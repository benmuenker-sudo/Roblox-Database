# Spiele abändern: Variation statt Kopie

> Stand: 2026-10-24 · Gesamt-Vertrauen: 🧠

## Kurzfassung
Inspiration ist erlaubt, Kopieren nicht. Du kannst ein erfolgreiches Prinzip verwenden, wenn du **mindestens 3 Bausteine bewusst veränderst** und eine **eigene Identität** schaffst. Das ist auch geschäftlich klüger: Die Discovery belohnt Spiele, die langfristig halten, nicht Klone mit demselben Event-Rhythmus.

## Rechtlicher und fairer Rahmen (🧠, keine Rechtsberatung)
- **Nicht übernehmen:** Namen, Logos, Charaktere, Texte, Sounds, Modelle, Skripte anderer Spiele.
- **Erlaubt:** Allgemeine Spielprinzipien (z. B. „Pflanzen wachsen lassen und verkaufen").
- **Im Zweifel:** Roblox-Nutzungsbedingungen und Community-Standards prüfen; bei starker Ähnlichkeit riskierst du Meldungen.

## Das Baustein-Modell
Jeder Baustein kann angepasst werden. Verändere mindestens 3.

| Baustein | Variationsfragen | Beispiel-Variation |
|---|---|---|
| **Fantasie/Setting** | Anderer Beruf, andere Welt, anderer Ton? | Garten → Unterwasser-Algenfarm |
| **Zeitstruktur** | Echtzeit-Timer, Runden, Tag/Nacht, Saisons? | Wachstum nur nachts |
| **Risiko** | Verlieren, bestohlen werden, Verfall, Wetter? | Ernte kann verderben |
| **Social** | Solo, Koop, PvP, Handel, Gilden? | Gemeinsame Insel mit Rollen |
| **Zufall** | Wie sichtbar, wie fair, wie viel Kontrolle? | Gezielte Kreuzung statt Zufallsmutation |
| **Meta** | Sammelbuch, Rebirth, Ranking, Saison, Museum? | Kuratiertes Museum |
| **Ästhetik** | Stil, Farbwelt, Humor, Sound | Handgemalt statt Low-Poly-Meme |
| **Monetarisierung** | Boosts, Slots, Skins, Saisonpass? | Kosmetik + Komfort statt Luck-Boost |

## Variationsmethoden

### A) „Invertieren"
Nimm eine Regel und kehre sie um. Stehlen → Beschützen/Verschenken; Wachsen lassen → Schrumpfen; Alleine → nur zu zweit spielbar.

### B) „Verschieben"
Dasselbe System in anderen Kontext: Farming im Weltraum, Pet-Sammeln als Foto-Safari, Tower Defense als Burgverteidigung gegen Wetter.

### C) „Kombinieren"
Zwei Loops verschmelzen, dritte Schicht darüber (siehe `ideen-methodik.md`).

### D) „Vertiefen"
Ein oberflächliches System tiefer machen: Statt Zufalls-Drops → Craftingbaum mit Entscheidungen.

### E) „Zielgruppe wechseln"
Ruhiger, kreativer, kooperativer. Es gibt viele Spieler, die den Stress der Top-Spiele nicht wollen.

## Beispiel: Variation eines Garten-Sammelspiels
**Original-Muster:** Pflanzen → warten → ernten → verkaufen → Zufallsmutationen → Events.
**Variation:**
1. Setting: Aquarium-Hobby statt Garten (Fantasie).
2. Social: Aquarien können besucht und bewertet werden (Social/Meta).
3. Zufall: Kreuzungen planbar über Gen-Regeln, Zufall nur bei Randmerkmalen (Zufall).
4. Monetarisierung: Kosmetik + zusätzliche Becken (Monetarisierung).
5. Ästhetik: Ruhiger Soundtrack, Wassergeräusche (Ästhetik).
Ergebnis: ähnlicher Komfort, eigenes Spiel.

## Checkliste „Bin ich noch Inspiration oder schon Kopie?"
- [ ] Mein Spiel hat einen eigenen Namen, eigenen Look, eigene Sounds.
- [ ] Mindestens 3 Bausteine sind sichtbar anders.
- [ ] Ein Spieler könnte mein Spiel in einem Satz von anderen unterscheiden.
- [ ] Ich habe kein Asset, keinen Text, keinen Charakter übernommen.
- [ ] Ich kann erklären, was *mein* Spiel besser macht, nicht nur „auch".

## Do / Don't
| Do | Don't |
|---|---|
| Prinzipien übernehmen, Ausdruck neu bauen | Assets/Charaktere/Sounds übernehmen |
| Eine Schwachstelle des Vorbilds gezielt lösen | Den Hit „billiger" nachbauen |
| Nische mit klarer Zielgruppe wählen | Mit Top-Spiel um dieselben Spieler konkurrieren |
