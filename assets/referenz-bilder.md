## Wie man ein Referenzbild analysiert (Raster)
1. **Erste Sekunde:** Was fällt zuerst auf? (Hierarchie)
2. **Farben:** Palette, Kontrast, Bedeutung
3. **Layout:** Wo sitzen welche Elemente? (Ecken, Mitte, unten)
4. **Dichte:** Wie viel Information gleichzeitig?
5. **Feedback-Hinweise:** Glühen, Partikel, Zahlen, Animationen (im Video prüfen)
6. **Mobile-Tauglichkeit:** Trefferflächen, Textgröße

## Muster, auf die man in Screenshots achten soll
| Muster | Erkennung im Bild |
|---|---|
| Währungsanzeige | Icon + Zahl in Ecke, meist gold/gelb, kurzes Zahlenformat |
| Seltenheitsrahmen | Farbige Ränder um Item-Karten (grau/grün/blau/lila/orange) |
| Fortschrittsbalken | Gefüllter Balken mit Zahl X/Y bei Quests/Sammelbuch |
| Benachrichtigungspunkt | Roter Punkt auf Menü-Icon bei Neuem |
| Event-Banner | Auffälliges Band oben/seitlich mit Timer |
| Boost-Icons | Kleine Symbole mit Countdown nahe HUD |
| Tutorial-Pfeil | Leuchtender Pfeil/Pfad zum nächsten Ziel |
| Shop-Karten | Icon, Name, Nutzen, Preis mit Robux-Symbol, Kaufbutton |
