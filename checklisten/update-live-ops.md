# Checkliste: Update / Event

## Vorbereitung
- [ ] Ziel des Updates (Retention? Umsatz? Neue Spieler?)
- [ ] Kennzahlen vorher notiert (CCU, D1/D7, Spielzeit, Umsatz)
- [ ] Event für alle erreichbar, ehrliche Fristen
- [ ] Balancing mit Wirtschaftstabelle geprüft (Inflation durch neue Boni?)

## Technik
- [ ] Test-Server/Test-Lauf
- [ ] Rollback-Plan
- [ ] Daten-Migration (Schema-Version) getestet
- [ ] Deploy außerhalb der Stoßzeit

## Kommunikation
- [ ] Update-Notes im Spiel
- [ ] Community-Ankündigung
- [ ] Thumbnail/Icon aktualisiert (ehrlich)

## Nachlauf
- [ ] Kennzahlen 24 h / 7 Tage danach
- [ ] Bug-Reports gesichtet
- [ ] Lehren in diese Datenbank eintragen (`CHANGELOG.md`)
