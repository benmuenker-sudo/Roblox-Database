# Checkliste: Prototyp (Core Loop)

## Umfang
- [ ] Nur Core Loop, hässlich ist okay
- [ ] Graybox-Map, Spawn nahe erster Aktion
- [ ] Platzhalter-UI, aber mobil bedienbar
- [ ] Feedback (Ton + visuell + Zahl) für Hauptaktion

## Tests mit 5–10 Spielern
- [ ] Beobachten, nicht erklären
- [ ] Zeit bis zur ersten Aktion gemessen
- [ ] Anteil, der nach 5 Minuten noch spielt
- [ ] „Noch eine Runde"-Wunsch erfragt
- [ ] Verwirrungspunkte notiert

## Auswertung
- [ ] Loop macht nach 30 Minuten noch Spaß?
- [ ] Welche 3 Dinge verbessern?
- [ ] Entscheidung: Weiterbauen / Umbauen / Stoppen
